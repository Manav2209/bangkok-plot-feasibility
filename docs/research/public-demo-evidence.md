# Public demonstration scope and additional site evidence

23 November 2026. The user does not have a personal parcel. That does not block use or
development of the application: the supplied draft permits a drawn illustrative boundary unless
cadastral evidence exists. Ownership/title verification is necessary for stronger claims about
actual property boundaries and rights, not mandatory to choose a public demonstration example.
Earlier handover requests that made a title number a prerequisite to the demo were too restrictive.

## Additional primary-source route: environmental-assessment files

The public ONEP route
https://eia.onep.go.th/services/web//doc/download-eia-method?id=3964
returned a scanned CASA CONDO SUKHUMVIT97 mitigation/monitoring and drawing bundle. The
downloaded source and rendered pages are retained only in ignored `tmp/pdfs`, not packaged as
public app assets. No image redistribution licence is assumed.

Visually inspected PDF page 2, printed 2/74, is signed September BE 2553 (2010). Its topographic
description says the project site was vacant, fenced and adjacent to Soi Sukhumvit 97. This is a
dated report description, not an independently dated site photograph or proof of vacancy today.
The drawing bundle includes a project-labelled 6 m road right-of-way. That is a project record
hosted by ONEP, not a retrieved current road-register survey. It cannot supply the width of the
current illustrative default or every segment with the same road name.

The developer's own [2013 shareholder-meeting minutes](https://investor.qh.co.th/storage/downloads/shareholders-meeting/agm2013/20130514-QH-AGM2013-Minutes-EN.pdf),
PDF page 5, include CASA CONDO SUKHUMVIT97 in the breakdown of 2012 condominium transfer
revenue. This establishes development/transfer activity after the 2010 vacant-condition report.
Consequently the historic description cannot justify replacing today's example with a purportedly
currently vacant parcel at that project. Exact georeferencing, whole-zone membership and a usable
site observation have not been established from this pass; no parcel outline was invented.

The ONEP route for another Regent 97/1 method file, identifier 7696, was located as a project-road
drawing lead, but not independently retrieved/visually verified here. It is not accepted evidence.

## Additional public-road register route

Official indexed project 62946 descriptions name Sukhumvit 97 and 97/1 among roads discussed
in the Phra Khanong local-highway registration activity. The visible reference is to ThL2/ThL3
road schedules. Direct attempts at the [publicly indexed BMA record](https://monitor.bangkok.go.th/monitor/pub-project/legacy?id=62946)
redirected to sign-in; no sign-in, CAPTCHA, private attachment or access-control bypass occurred.
The [public policy site](https://policy.bangkok.go.th/watch/) remains reachable, but this pass did
not retrieve a road-segment register attachment with the current legal boundaries and width.
An indexed description of registration activity is not that missing segment-level record.

## Result for the app

Keep the existing 2,500 m² outline explicitly illustrative. Retain real context buildings, unknown
vacancy/road evidence and the distinction between passed study settings and unresolved statutory
checks. The user can use Reset example without supplying or owning land. A title record is not
requested as a mandatory demo input.

This additional search established a useful historical description and a reason not to treat it
as current vacancy. It did not establish a replacement currently vacant, source-supported default.
Choosing a stronger public example remains research work; it does not depend on the user having
a personal property. Current design/test evidence is unchanged by the scope and copy clarification.
